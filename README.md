> A Deep Learning comparative analysis to classify images as either Authentic (Real) or Synthetic (AI-Generated).

## Overview
With the rapid advancement of generative AI, distinguishing synthetic images from authentic photographs has become a critical challenge. This repository contains the implementation of an image classification system designed to solve this problem. The project evaluates and compares three deep learning architectures: **Custom CNN (trained from scratch), MobileNetV2, and EfficientNetB0 (Transfer Learning)**. 

## Key Results & Performance
The models were evaluated comprehensively based on their ability to correctly classify unseen images in the testing dataset.

| Model Architecture | Accuracy | Precision | Recall | F1-Score |
| :--- | :---: | :---: | :---: | :---: |
| **Custom CNN (Baseline)** | 64.89% | 65.15% | 65.15% | 65.15% |
| **MobileNetV2** | 77.10% | 80.00% | 72.73% | 76.19% |
| **EfficientNetB0** | 84.73% | 83.82% | 86.36% | 85.07% |
| **EfficientNetB0 + Augmentation** | 86.26% | 87.50% | 84.85% | 86.15% |
| **EfficientNetB0 + Aug + Fine-Tuning** | **87.02%** | **87.69%** | **86.36%** | **87.02%** |

*(Note: The best performing model was EfficientNetB0, which was further optimized using Fine-Tuning in Scenario 3).*

## Repository Structure & Methodology
The project is structured sequentially into Jupyter Notebooks, following the research methodology:

| File | Description |
| :--- | :--- |
| `01_split_resize_dataset.ipynb` | Dataset cleaning, class balancing (undersampling), resizing to 224x224, and splitting (70% Train, 15% Val, 15% Test). |
| `02_cnn_custom.ipynb` | Baseline model training using a custom 4-block Convolutional Neural Network. |
| `03_mobile_net_v2.ipynb` | Transfer learning implementation using MobileNetV2 (pretrained on ImageNet). |
| `04_EfficientNetB0.ipynb` | Transfer learning implementation using EfficientNetB0 (pretrained on ImageNet). |
| `05_EfficientNetB0_WithAugmentation.ipynb` | **Scenario 2:** Applying Data Augmentation (Flip, Rotation, Translation, Zoom, Contrast) to the best-performing model. |
| `06_EfficientNetB0_FineTuning.ipynb` | **Scenario 3:** Unfreezing selected layers for Fine-Tuning to adapt to the dataset characteristics. |

## Dataset & Experimental Configuration
*   **Dataset:** [AI Generated vs Real Images Dataset](https://www.kaggle.com/datasets/cashbowman/ai-generated-images-vs-real-images) from Kaggle.
*   **Total Images:** 868 images (Balanced: 434 AI, 434 Real). Input size configured to 224 × 224 pixels in RGB.
*   **Hyperparameters:** Optimized using Adam (LR: 0.001), Binary Crossentropy loss, Batch Size of 32, for 20 Epochs.

## Conclusion & Insights
*   **Transfer Learning Superiority:** Pretrained models (EfficientNetB0 and MobileNetV2) significantly outperformed the Custom CNN baseline, proving the effectiveness of ImageNet weights in extracting low-level visual features even for synthetic images.
*   **Data Augmentation & Fine-Tuning Impact:** The addition of data augmentation improved the model's ability to generalize, reducing misclassifications. Unfreezing the top layers of EfficientNetB0 (fine-tuning) pushed the final accuracy and F1-score to an impressive 87.02%, effectively learning the specific artifacts generated by AI.
